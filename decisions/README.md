# Decisions

The records of this repository's own design choices, one per file, numbered in order. Each follows the
[decision record](../shapes/decision-record.md) shape, which extends reader-ergonomics' general one: what was decided,
in what context, the options that lost and why, and the consequences. A record is not rewritten once accepted: a later record supersedes it, and both stay.
